# 재무 대시보드

개인용 재무 관리 대시보드. 여러 계좌에 흩어진 자산을 한 곳에서 보고, 위험/안전 비중을 자동 계산하고, 연도별 자산 추이를 시뮬레이션하고, 내 집 마련 자금 계획을 관리합니다.

## 구조

- `client/` — React + TypeScript (Vite), 화면
- `server/` — Express + TypeScript, API + 로컬 파일 저장
- `data/` — 실제 자산 데이터가 저장되는 곳 (`.gitignore` 처리됨, 커밋되지 않음)

데이터는 브라우저 localStorage가 아니라 `data/finance-dashboard.json` 파일에 저장되므로, 브라우저 캐시를 지워도 데이터가 유지됩니다.

## 실행 방법

최초 1회:

```bash
npm run install:all
```

개발 모드로 실행 (서버 + 클라이언트 동시 실행, 저장 즉시 반영):

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

평소에 계속 켜두고 쓸 때는 빌드된 버전을 서버 하나로 띄우는 게 더 간단합니다:

```bash
npm start
```

브라우저에서 `http://localhost:4300` 접속.

## 기능

화면 위쪽 탭은 자주 쓰는 순서(1~6)가 앞에, 가끔 여는 보조 탭(7~9)이 구분선 뒤에 있습니다.

1. **개요** — 집 마련 '이대로면?' 요약(목표별 도달 시점·예정일 대비 빠름/늦음, 늦으면 월 얼마를 더 모아야 맞는지, 목표 집값 상환 부담 판정), 점검할 것(만기·연금/청약 한도·정책 숫자 확인 등 알림), 이번 달 정리(잔액 갱신 → 연금·청약·카드 입력 → 히스토리 기록 → 리밸런싱 확인), 자산 합계와 전체 자산 추이, 위험/안전 비중, 집 마련 진행·예상 경로 그래프(수익률 반영 토글), 비상금(지출 몇 개월 치인지), ISA 의무가입 D-day, 요약 메모
2. **자산 스냅샷** — 계좌별 잔액 입력/편집(적금·예금 만기일 포함), xlsx 가져오기, 월간 리포트(두 기록 사이 자산 변화를 넣은 돈·운용 수익·그 외로 나누고 분류·계좌별 변화 표시, 기록 전 미리보기, 잔액이 ±10% 넘게 달라진 계좌 경고, '요약 복사' 버튼), 배당·이자 수입 기록과 상품별 예상 연 수입, 투자원금 대비 수익률, 연도별 수익률(넣은 돈 제외)과 지수·금리 비교, 히스토리와 자산 그래프
3. **리밸런싱** — 집 자금·노후 자금 묶음별 목표 비중(글리드 패스), 팔고 살 상품 추천, 계좌 간 이동(계좌별 입금 가능 금액), 새로 넣을 돈만으로 맞추기, 예상 수수료·세금, 시세 자동 불러오기. 위험자산은 스냅샷에 위험 상품이 있는 계좌에서만 삽니다.
4. **연말정산** — 연금저축·IRP, 월세, 주택청약, 신용·체크카드 공제로 줄어드는 세금 추정, 공제 기준 숫자 설정, 세금 우대 계좌 점검(ISA 납입·비과세 한도, 금융소득종합과세 접근 경고, 배당·이자 큰 상품의 계좌 위치 추천)
5. **시뮬레이션** — 투자자산 또는 전체 자산 기준 복리 성장. 연간 적립액(내 정보 탭 값으로 자동 계산 또는 직접 입력)을 매달 나눠 넣는 월 단위 계산이며, 개요의 집 마련 예상 경로와 같은 계산을 씁니다. 수익률·저축액을 흔들었을 때 결과가 달라지는 민감도 표와 은퇴 시뮬레이션(4% 룰 필요 자산, 기대수명까지 버티는지)도 여기 있습니다.
6. **내 집 마련** — 목표 집값과 견줘 볼 다른 집값의 필요 대출·월 상환(30/40년)·상환 비중 판정, 보금자리론·디딤돌 자격 배지, 최대 적정 집값, 연봉 기준 도달 연도, 정책 숫자 설정(확인일 1년 경과 알림), 수익률·저축액에 따른 목표 도달 시점 민감도 표. 목표 집값은 내 정보 탭에서 바꿉니다.
7. **내 정보** — 여러 화면이 같이 쓰는 값을 한곳에서 입력: 월 실수령액·연 총보수·연봉 상승률, 지출 예산, 연금 납입 계획(세액공제율 자동), 집 매수 예정일·목표 집값·대출 금리·계약상 월세, ISA 의무가입 종료일 (각 칸에 '쓰이는 곳' 표시)
8. **체크리스트** — 정기적으로 확인할 항목 관리(날짜를 넣으면 가까워질 때 개요에 알림, 연금·청약 한도와 환급 금액 자동 표시)
9. **데이터** — 백업·복원, JSON 내보내기·가져오기

### 시세와 비교 기준

리밸런싱의 1주 가격 불러오기와 연도별 수익률의 지수 비교(기본: S&P500·코스피200 ETF 종가)는 공공데이터포털 서비스 키가 필요합니다. 키는 리밸런싱 탭의 '가격 불러오기'에서 등록하며 `data/secrets.json`에만 저장됩니다. 키가 없으면 금리 기준만 비교됩니다. 비교 기준은 연도별 수익률 아래 '비교 기준 설정'에서 바꿀 수 있고, 받아 온 시세는 `data/benchmark-cache.json`에 12시간 캐시됩니다. ETF 종가 기준이라 분배금은 빠집니다.

## 테스트

```bash
npm test
```

서버·클라이언트의 단위 테스트를 모두 실행합니다. 테스트는 임시 폴더를 쓰므로 실제 `data/`는 건드리지 않습니다.

## 데이터 백업

`data/finance-dashboard.json` 파일 하나에 모든 데이터가 들어있습니다. 저장할 때마다(10분에 한 번) `data/backups/`에 자동 백업이 쌓이고(최근 30개), 앱의 **데이터** 탭에서 복원·내보내기·가져오기를 할 수 있습니다(`data/`의 키·캐시 파일은 백업 대상이 아닙니다).
