# 재무 대시보드

개인용 재무 관리 대시보드. 여러 계좌에 흩어진 자산을 한 곳에서 보고, 위험/안전 비중을 자동 계산하고, 연도별 자산 추이를 시뮬레이션하고, 내 집 마련 자금 계획을 관리합니다.

## 구조

- `client/` — React + TypeScript (Vite), 화면
- `server/` — Express + TypeScript, API + 로컬 파일 저장
- `data/` — 실제 자산 데이터가 저장되는 곳 (`.gitignore` 처리됨, 커밋되지 않음)

데이터는 브라우저 localStorage가 아니라 `data/finance-dashboard.json` 파일에 저장되므로, 브라우저 캐시를 지워도 데이터가 유지됩니다.

## 실행 방법

최초 1회:

```bash
npm run install:all
```

개발 모드로 실행 (서버 + 클라이언트 동시 실행, 저장 즉시 반영):

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

평소에 계속 켜두고 쓸 때는 빌드된 버전을 서버 하나로 띄우는 게 더 간단합니다:

```bash
npm start
```

브라우저에서 `http://localhost:4300` 접속.

## 기능

1. **개요** — 점검할 것(알림), 자산 합계, 위험/안전 비중, 집 마련 진행·예상 경로 그래프, ISA 의무가입 D-day, 요약 메모
2. **자산 스냅샷** — 계좌별 잔액 입력/편집, xlsx 가져오기, 투자원금 대비 수익률, 히스토리와 자산·수익률 그래프
3. **월급·예산** — 월 실수령액, 생활비·주거비 예산, 연금저축·IRP 세액공제 한도 추적
4. **리밸런싱** — 집 자금·노후 자금 묶음별 목표 비중(글리드 패스), 팔고 살 상품 추천, 계좌 간 이동, 새로 넣을 돈만으로 맞추기, 예상 수수료·세금, 시세 자동 불러오기
5. **연도별 시뮬레이션** — 복리 기반 자산 성장, 시나리오 비교, 집 자기자금 도달 시점
6. **내 집 마련** — 집값 후보별 필요 대출·월 상환(30/40년)·상환 비중 판정, 보금자리론·디딤돌 자격 배지, 최대 적정 집값, 연봉 기준 도달 연도, 정책 숫자 설정(확인일 1년 경과 알림), 목표 집값·LTV 계산
7. **체크리스트** — 정기적으로 확인할 항목 관리
8. **데이터** — 백업·복원, JSON/엑셀 내보내기, JSON 가져오기

## 테스트

```bash
npm test
```

서버·클라이언트의 단위 테스트를 모두 실행합니다. 테스트는 임시 폴더를 쓰므로 실제 `data/`는 건드리지 않습니다.

## 데이터 백업

`data/finance-dashboard.json` 파일 하나에 모든 데이터가 들어있습니다. 저장할 때마다(10분에 한 번) `data/backups/`에 자동 백업이 쌓이고(최근 30개), 앱의 **데이터** 탭에서 복원·내보내기·가져오기를 할 수 있습니다.
